# Calibre-Web Automated for umbrelOS

A test build of [Calibre-Web Automated](https://github.com/crocodilestick/Calibre-Web-Automated), packaged for umbrelOS.

This community package is vibecoded: built with AI assistance, human review, and an optimistic number of compose-file rereads.

## Install from the community app store

1. Open the App Store on your umbrelOS device and add a community app store.
2. Enter `https://github.com/telskamp/calibre-web-automated-umbrel`.
3. Open the **Telskamp CWA App Store**, select **Calibre-Web Automated**, and install it.
4. Sign in with the upstream default credentials `admin` / `admin123` and change the password.

The first-run library location is `/calibre-library`. Put books to be processed into `/cwa-book-ingest`. CWA removes files from the ingest folder after processing, so do not use it as a download destination.

This is an independently maintained community package, not an official Umbrel App Store listing.

An official App Store submission is also under review: [getumbrel/umbrel-apps#6189](https://github.com/getumbrel/umbrel-apps/pull/6189).
